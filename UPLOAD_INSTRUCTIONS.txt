GITHUB WEB UPLOAD PACKAGE
=========================

1. Extract this ZIP and open the folder inside it.
2. Upload EVERY file inside that folder to the ROOT of the GitHub repository.
3. Do not upload the outer folder as a nested project directory.
4. Do not delete any flat_* file. restore-project.mjs reconstructs the original folders during the Cloudflare build.
